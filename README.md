Moogsoft is an AIOps platform for IT operations, DevOps and SRE teams that ingests events, alerts and metrics from across a hybrid estate, deduplicates and reduces noise, correlates related alerts into incidents, detects anomalies in metric streams, and surfaces probable root cause and similar past incidents so responders can act faster. Founded in 2011 by Phil Tee and Mike Silvey, Moogsoft was acquired by Dell Technologies in October 2023 and the SaaS product is now sold as Dell APEX AIOps Incident Management, while the moogsoft.com brand, documentation and API surface remain live. The platform is API-first: seventeen public OpenAPI 3.1 contracts covering alerts and incidents, configuration, catalogs, correlation definitions, maintenance windows, collectors, inbound event/metric integrations, bring-your-own integrations, on-call scheduling, outbound webhooks, workflow automation, user and API-key management are published from api.moogsoft.ai and documented on a public Stoplight portal at api.docs.moogsoft.com.

**Areas:** AIOps · Incident Management · Observability · Alerting · Anomaly Detection · Correlation · On-Call · Monitoring · IT Operations · DevOps · SRE

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Moogsoft: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
