# Moogsoft (Dell APEX AIOps Incident Management)

> Moogsoft is an AIOps platform for IT operations, DevOps and SRE teams. It ingests events, alerts and
> metrics from across a hybrid estate, deduplicates them into alerts, correlates alerts into incidents,
> detects anomalies in metric streams, and surfaces probable root cause and similar past incidents.
> Acquired by Dell Technologies in October 2023; the SaaS product is sold as Dell APEX AIOps Incident
> Management while the moogsoft.com brand, documentation and API surface remain live.

Base URL: https://api.moogsoft.ai — authenticate with an `apiKey` request header on every call.

## How the API behaves

- **Auth**: `apiKey` header. Keys inherit the creating user's permissions and can never exceed them.
- **Operation classes**: Moogsoft calls all GETs *safe* and POST/PATCH/DELETE *advanced* — advanced
  operations change platform behaviour immediately (deleting a correlation definition changes how
  incidents form on the very next alert).
- **Pagination**: `start` + `limit`, plus a `search_after` cursor on alerts and incidents. Every GET
  returns at most **1000 records**.
- **Idempotency**: none. There is no Idempotency-Key header; a retried POST duplicates.
- **Errors**: `{"status":"error","message":"...","additional":[...]}` as `application/json`. Not RFC 9457,
  no machine-readable error code — branch on the HTTP status.
- **Rate limits**: no published numbers and no rate-limit response headers. Moogsoft reserves the
  right to apply discretionary concurrency and rate limits.
- **Versioning**: per-service path major version (`/v1`, `/v2`, one `/v3`). Existing versions are
  supported for up to 6 months before sunset. No Sunset or Deprecation headers are emitted.
- **Reversibility**: maintenance-window occurrences can be cancelled or skipped before they start.
  Deletes of catalogs, correlation definitions, workflows, integrations, users, roles and views have
  no restore path and no stated retention window.
- **Dry run**: real rehearsal endpoints exist — preview/test a webhook, test/validate an event, alert
  or incident workflow, test a CloudWatch integration.
